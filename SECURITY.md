# Security Policy

🛡️ Segurança e Compliance (RBAC)
O sistema utiliza Role-Based Access Control, garantindo que Stakeholders de Sourcing nunca tenham acesso a dados sensíveis de outros fornecedores, mantendo a ética concorrencial exigida em processos de auditoria externa.
